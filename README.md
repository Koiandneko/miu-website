# MIU · 宣传网页

独立静态网站，无构建步骤，无外部字体、CDN 或运行依赖。双击 `index.html` 即可本地查看。桌面和手机均有适配。

## 文件

- `index.html`：宣传文案、角色、场景与开场节选。
- `style.css`：黑白手绘与柠檬黄主题、响应式布局。
- `script.js`：台词翻页。
- `assets/`：从游戏 assets 复制的 8 张原始图片。没有修改原资源。
- `.nojekyll`：静态托管辅助文件。

网页所需内容全部在本目录内，不需要上传游戏工程、完整剧本或 dist。所有资源使用相对路径，支持 GitHub Pages 的仓库子路径，也能离线查看。

## 之后上传 GitHub Pages

推荐新建专门的宣传网页仓库，把本目录**里面的内容**上传至仓库根目录，让 `index.html` 位于根目录。随后在仓库的 Pages 设置里启用分支部署，选择存放文件的分支及根目录，等待部署完成。访问地址以 GitHub Pages 设置中显示的地址为准。

如果将整个 `promo-site` 目录放进已有的 Pages 仓库，需要以该仓库发布地址加上 `/promo-site/` 访问，并确保该目录包含在发布内容中。

宣传页仓库：https://github.com/Koiandneko/miu-website 。GitHub Pages 通过 main 分支的根目录发布。

## 后续维护

游戏正式标题为“MIU”。她、勿一、夜光游水母的英文名分别为 MIU、UI、KURAGE。立绘对应关系来自原项目，故事介绍基于提供的剧本；未公开结局。角色简介中的引导语为宣传文案。试读完整呈现“你真的要跟着？”至“那就一直跟着。”及随后的旁白收尾，共 11 页。旁白不显示姓名标签，不另设结束标签页。

尚未提供发行日期、售价或下载地址，因此页面没有虚构发布状态或下载按钮。准备好正式下载链接后，可在 `index.html` 最后的 `ending` 区域增加真实链接。

图片与剧本文案沿用游戏现有素材，不另行声明新的授权。此目录没有对原项目文件做更改。
